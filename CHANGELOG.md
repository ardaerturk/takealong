# Changelog

## 0.3.0 · November 25, 2026

Kitwake is now **Takealong**. The launcher is `takealong` on Linux and `takealong.exe` on Windows. Your existing workspace, Codex sessions, and recipes still work. For an existing stick, copy your `Start.md` and personal recipes to the new kit.

## 0.2.0 · November 25, 2026

Choose the first task with `Start.md`. Opening Kitwake starts a fresh chat with that message. An explicit command always takes precedence.

## 0.1.0 · November 25, 2026

First public release. Open Codex from a USB drive on x64 Linux or Windows, run a Markdown recipe, and resume work locally or over SSH. The kit includes Codex CLI 0.172.0.
