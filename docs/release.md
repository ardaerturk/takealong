Download **kitwake-usb.zip**, extract the **Kitwake** folder, and copy it to your USB drive. On Linux run `./kitwake`. On Windows open `kitwake.exe`.

To start with the same task each time, write it in **Start.md** next to the launcher. Opening Kitwake starts a new chat with that message.

The kit includes Codex CLI for x64 Linux and Windows. Bring your own login, run a plain text recipe, or resume a session on its original computer over SSH.

[Read the guide](https://github.com/ardaerturk/kitwake#start-here). Use **SHA256SUMS** to verify your download.
