Kitwake is now **Takealong**. Already have a stick? Keep your old folder, then copy your `Start.md` and personal recipes into the new kit. Existing Codex sessions and workspaces stay on their original computer.

Download **takealong-usb.zip**, extract the **Takealong** folder, and copy it to your USB drive. On Linux run `./takealong`. On Windows open `takealong.exe`.

To start with the same task each time, write it in **Start.md** next to the launcher. Opening Takealong starts a new chat with that message.

The kit includes Codex CLI for x64 Linux and Windows. Bring your own login, run a plain text recipe, or resume a session on its original computer over SSH.

[Read the guide](https://github.com/ardaerturk/takealong#start-here). Use **SHA256SUMS** to verify your download.
