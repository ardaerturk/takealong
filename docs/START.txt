Kitwake
A coding agent you can carry.

Linux: open this folder in a terminal and run ./kitwake
Windows: double-click kitwake.exe

Sign in when prompted. Use a computer you trust.
To see every command, run ./kitwake --help (Windows: .\kitwake.exe --help).

Open a project      kitwake open <folder>
Brief a project     kitwake brief <folder>
Continue a session  kitwake resume

Want the same first task each time? Write it in Start.md next to the
launcher. Open Kitwake to start a new chat with that message.
Add a Markdown file to recipes/ to keep other tasks you can run by name.
Keep the runtime folder next to the launcher. No install is required.

Guide and source: https://github.com/ardaerturk/kitwake
